# Plug Shot

A 2D pixel-art trickshot game. Your phone is on 3%, the outlet is across the room, and you are not getting up. Drag back to aim, let go to throw the charger, and land the plug in the socket.

- 47 rooms, sorted from easy to hard
- Endless mode with rooms generated on the fly
- A daily challenge room
- Unlockable hoodies and plug skins

Play it: https://down1oads.github.io/Plug-Shot/

The whole game is one file, `index.html`, with no build step.
